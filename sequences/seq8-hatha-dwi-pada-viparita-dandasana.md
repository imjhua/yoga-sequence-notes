# 하타-드위파다비파리타단다사나

**포커스:** 흉추 신전 · 어깨 가슴 열기 · 허벅지 내전근 강화 · **피크포즈:** 드위파다비파리타단다사나

## 개요

- **핵심 cue**: 허벅지 안쪽(내전근) 모으는 힘 인지 · 흉추와 가슴의 점진적 확장 · 어깨 회전 및 목/등의 정렬
- **수련 포인트**: 
  - 바즈라/비라사나의 하체 안정성을 기반으로 타파스와 파르바타를 통해 상체 공간 확장
  - 등 뒤 합장 및 우르드바무카로 어깨 앞면과 가슴을 충분히 연 후 부장가사나로 이어지는 후굴 준비

---

## 1. 바즈라 - 타파스 - 바즈라

| 포즈 | # | 동작 |
|---|---|---|
| **바즈라사나** | 1 | 무릎을 꿇고 발등을 바닥에 내려두어 바즈라사나로 앉기 |
| | 2 | 척추를 곧게 세우고 호흡을 정돈 |
| **타파스** | 3 | `inhale` 가슴을 열어내며 열기(Tapas)를 일으키는 척추 신전 |
| | 4 | `exhale` 어깨 긴장을 풀고 가슴 중심에 집중 |
| **바즈라사나** | 5 | 바즈라사나로 돌아와 호흡 고르기 |

## 2. 비라 - 갸냐 - 파르바타 (허벅지 모으기)

| 포즈 | # | 동작 |
|---|---|---|
| **비라사나** | 1 | 무릎을 모으고 종아리 살을 바깥으로 꺼내며 엉덩이를 바닥에 안착 |
| | 2 | 양 발날이 골반 옆에 가지런히 놓이도록 정렬 |
| **갸냐무드라** | 3 | 엄지와 검지 끝을 맞대어 갸냐무드라, 손등을 무릎 위에 올리기 |
| | 4 | 깊게 호흡하며 척추를 위아래로 길게 늘이기 |
| **파르바타사나** | 5 | `inhale` 손가락 깍지 껴서 손바닥을 천장 높게 밀어올리기 |
| | 6 | **허벅지 안쪽(내전근)을 서로 강하게 조여내는 힘** 유지 |
| | 7 | `exhale` 갈비뼈를 닫고 척추 마디마디를 위로 확장 |

## 3. 바즈라 - 타파스 - 파르바타 (눈 감고) - 비라

| 포즈 | # | 동작 |
|---|---|---|
| **바즈라사나** | 1 | 엉덩이를 들어 다시 바즈라사나로 정렬 |
| **타파스** | 2 | `inhale` 가슴을 앞으로 위로 확장하며 타파스 연결 |
| **파르바타사나** | 3 | 손가락 어색한 방향으로 깍지 끼워 머리 위로 기지개 |
| | 4 | **눈을 지그시 감고** 내면의 호흡과 척추 축의 확장에 집중 |
| | 5 | 어깨가 솟지 않도록 견갑골을 등 뒤로 끌어내리기 |
| **비라사나** | 6 | `exhale` 팔을 천천히 풀며 다시 비라사나로 전환하여 안정 |

## 4. 바즈라 - 등 뒤 합장 - 우르드바무카 - 다운독 - 아쉬탕가나마스카라 - 부장가사나

| 포즈 | # | 동작 |
|---|---|---|
| **바즈라사나** | 1 | 바즈라사나로 돌아와 앉기 |
| **등 뒤 합장** | 2 | 등 뒤에서 두 손바닥을 마주 대어 합장 (파스치마 나마스카라) |
| | 3 | 손바닥을 서로 밀어내며 팔꿈치를 뒤로 열어 가슴을 활짝 확장 |
| **우르드바무카** | 4 | `inhale` 턱을 가볍게 들어 목 앞선을 길게 늘이고 시선 천장 (우르드바무카) |
| | 5 | 가슴 중앙을 하늘 높이 끌어올리기 |
| **다운독** | 6 | `exhale` 손을 풀고 손바닥 매트 앞쪽을 짚어 다운독(아도무카스바나사나)으로 전환 |
| | 7 | 손바닥으로 바닥을 밀어내며 좌골을 천장 높게, 척추 후면 이완 |
| **아쉬탕가나마스카라** | 8 | `inhale` 플랭크로 이동 후 무릎 바닥 |
| | 9 | `exhale` 가슴과 턱을 손 사이 바닥에 내려놓기 (8지 점지) |
| | 10 | 엉덩이는 높게 유지하고 흉추의 부드러운 전방 굴곡 느끼기 |
| **부장가사나** | 11 | `inhale` 발등과 치골을 바닥에 밀착하며 상체를 부드럽게 일으켜 부장가사나 |
| | 12 | 치골 바닥 누르고 어깨를 귀와 멀어지게 끌어내리기 |
| | 13 | `exhale` 호흡 유지하며 척추 전체의 기립근 각성 |
