# 힐링-중심잡기 & 브륵샤사나

**포커스:** 안타라반다 · 내전근 강화 · 중심잡기 · **피크포즈:** 브륵샤사나 (나무 자세)

## 개요

- **핵심 cue**: 안타라반다(몸통 중심선으로 모으는 힘) · 허벅지 안쪽(내전근)의 상호 저항 · 발바닥 3점 접지와 골반 수평
- **수련 포인트**:
  - 수카사나와 캣-카우에서부터 무릎과 허벅지를 모으는 감각을 일깨워 중심선(Midline) 인지
  - 태양경배 변형과 테이블 변형으로 상하체 중심 제어력을 기르고, 하이런지를 통해 단단한 하체 기반 구축
  - 피크포즈인 브륵샤사나에서 갸냐무드라, 아르다받다, 측면 기울기 등 점진적 변형을 통해 균형 감각 심화

---

## 1. 수카사나 & 안타라반다 인식

| 포즈 | # | 동작 |
|---|---|---|
| **수카사나** | 1 | 편안한 수카사나로 앉아 좌골을 바닥에 고르게 정렬 |
| | 2 | 손등을 무릎 위에 올려두고 어깨 힘 풀기 |
| **안타라반다 호흡** | 3 | `inhale` 척추 마디마디를 천장 방향으로 곧게 세우기 |
| | 4 | `exhale` 회음부와 하복부를 가볍게 끌어당기며 몸의 중심선(안타라반다) 자각 |
| **풀기 동작** | 5 | 턱을 쇄골 쪽으로 당겨 목 뒤선 늘이기 |
| | 6 | 좌우로 천천히 고개 돌리며 목·어깨 긴장 완화 |
| | 7 | 가벼운 상체 비틀기로 척추와 골반 순환 돕기 |

## 2. 캣-카우 & 모은 테이블 (무릎 들기)

| 포즈 | # | 동작 |
|---|---|---|
| **테이블 포즈** | 1 | 네발 기기 자세로 전환하여 손목-어깨, 무릎-골반 수직 정렬 |
| **캣-카우** | 2 | `inhale` 꼬리뼈를 천장으로, 가슴을 앞으로 밀어내며 소 자세 |
| | 3 | `exhale` 등을 둥글게 말아 시선 배꼽, 척추 분절 이완 |
| **다리 모은 테이블** | 4 | **두 무릎과 발 안쪽을 완전히 밀착**하여 다리 모으기 |
| | 5 | 허벅지 안쪽(내전근)을 서로 강하게 조여내는 힘 인지 |
| **무릎 들기 (호버)** | 6 | 발끝을 바닥에 세우고 |
| | 7 | `exhale` 복부를 당기며 **무릎을 바닥에서 2~3cm만 살짝 들어올려 유지** (3~5호흡) |
| | 8 | 내전근과 하복부 코어의 단단한 결합 느끼기 |

## 3. 태양경배 변형

| 포즈 | # | 동작 |
|---|---|---|
| **수리야나마스카라 준비** | 1 | 매트 앞쪽에서 타다사나로 서기 |
| **무릎 바닥 닿을듯** | 2 | `inhale` 두 팔 머리 위로 우르드바 하스타사나 |
| | 3 | `exhale` 우타나사나 상체 숙이기 |
| | 4 | `inhale` 아르다 우타나사나 척추 펴기 |
| | 5 | 플랭크로 이동 후 차투랑가로 내려갈 때, **무릎이 바닥에 닿을락 말락 1cm 위에서 제어** |
| **팔꿈치 바닥 닿을듯** | 6 | 다운독 또는 플랭크 전환 시 **양 팔꿈치를 바닥 가까이 천천히 낮추며** 상체 중심력 제어 |
| | 7 | 부장가사나 또는 업독으로 가슴 열기 |
| | 8 | 다운독으로 연결하여 호흡 정리 |

| | 2 | 오른 발날 전체를 바닥에 밀착하여 허벅지 안쪽 내전근 스트레칭 |

## 6. 피크포즈: 브륵샤사나 (나무 자세 변형)

| 포즈 | # | 동작 |
|---|---|---|
| **브륵샤사나 기본** | 1 | 타다사나에서 오른발 바닥을 왼 허벅지 안쪽에 밀착 |
| | 2 | **발바닥과 허벅지 안쪽이 서로 밀어내는 반작용**으로 중심 잡기 |
| | 3 | 골반이 열리거나 틀어지지 않도록 수평 정렬 |
| **변형 1 (갸냐무드라)** | 4 | 두 손 엄지와 검지를 맞대어 갸냐무드라, 가슴 앞 또는 무릎 위 올려 호흡 안정 |
| **변형 2 (아르다받다)** | 5 | 가능하면 오른 발등을 왼쪽 서혜부 깊숙이 올려 아르다받다파드마 브륵샤사나 |
| | 6 | 척추를 더 곧게 세우고 지지하는 다리의 기반 단단히 유지 |
| **변형 3 (측면 기울기)** | 7 | 오른손을 오른 무릎 쪽에 두고, 왼팔을 하늘 위로 뻗어 오른쪽으로 상체 기울이기 |
| | 8 | 흔들림 속에서 발바닥과 내전근의 중심 회복력 경험 |
